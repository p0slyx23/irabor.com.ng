# Portfolio fonts

Manrope variable font, self-hosted to avoid a third-party font request.

- Source: https://github.com/google/fonts/tree/main/ofl/manrope
- Font file: `Manrope-Variable.ttf` (upstream `Manrope[wght].ttf`)
- License: SIL Open Font License 1.1, included as `OFL-Manrope.txt`

Manrope remains the navigation and case-study typeface. The three-section
portfolio uses self-hosted Inter for its identity and reading column.

- Inter source: https://github.com/rsms/inter/tree/master/docs/font-files
- Font file: `Inter-Variable.woff2` (upstream `InterVariable.woff2`)
- License: SIL Open Font License 1.1, included as `Inter-OFL.txt`

Code retains the system monospace stack.
